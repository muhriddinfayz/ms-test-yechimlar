Boshqaruv paneli

Saytda qaysi prezentatsiyalar ko‘rinishini belgilang va «Saqlash»ni bosing.

Kirish

GitHub tokeningizni kiriting. Token faqat shu qurilmadagi brauzerda saqlanadi va faqat GitHub’ga yuboriladi.

Token qanday olinadi?
  1. github.com/settings/personal-access-tokens/new sahifasini oching.
  2. Token name: masalan MS boshqaruv; Expiration: o‘zingiz tanlang.
  3. Resource owner: muhriddinfayz.
  4. Repository access: Only select repositories → ms-test-yechimlar ni tanlang («Public repositories» bo‘lsa faqat o‘qiy oladi, saqlay olmaydi).
  5. Permissions → Repository permissions → Contents → ochiladigan ro‘yxatdan Read and write (odatda «Read-only» turadi — uni almashtiring).
  6. Generate token → tokenni nusxalab shu yerga qo‘ying.
Kartochkani bosing — ko‘rinadi / yashirin. Yashirin prezentatsiyalar bosh sahifada chiqmaydi va havola orqali ham ochilmaydi (faqat siz kirgan qurilmada ochiladi).
